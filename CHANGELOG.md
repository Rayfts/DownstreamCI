# Changelog

This file records notable user-facing changes to DownstreamCI. The project is currently pre-1.0, so configuration and deployment details may evolve while the deterministic compatibility model stabilizes.

## Unreleased

No tagged public release has been declared yet. Future features, fixes, ecosystem compatibility changes, security-relevant behavior changes, and breaking configuration changes should be summarized here before release.

## Initial public foundation

The current foundation includes deterministic baseline/candidate classification, Docker isolation, npm/Python/Cargo/Go ecosystem adapters, GitHub Action/App integration, worker and dashboard components, evidence/history storage, and the initial coding-agent analysis adapter set. Earlier development history is preserved in Git.
